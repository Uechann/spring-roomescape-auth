## 목적
- 사용자가 웹에서 로그인한다.
- 로그인한 사용자를 기준으로 예약을 생성한다.
- 로그인한 사용자를 기준으로 예약을 조회한다.
- 로그인하지 않은 사용자는 인증이 필요한 기능을 사용할 수 없다.
- 인증 로직이 컨트롤러마다 반복되지 않게 한다.
